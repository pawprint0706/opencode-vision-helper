# Security policy

## Supported version

Security fixes are provided for the latest published version. Before the first npm
release, the current `main` branch is the only maintained code line.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials,
private images, provider responses, or sensitive OpenCode configuration in a report.
Use GitHub's private vulnerability-reporting flow for
`pawprint0706/opencode-vision-helper`:

https://github.com/pawprint0706/opencode-vision-helper/security/advisories/new

Include the affected version or commit, operating system, Node.js and OpenCode
versions, minimal reproduction steps, and sanitized impact. Use synthetic fixtures
where possible. The maintainer will acknowledge the report through GitHub, assess
the affected versions, and coordinate remediation and disclosure there.

OpenCode owns provider credentials. This project will never ask a reporter to copy
an API key, token, auth file, or private image into an issue or advisory.
