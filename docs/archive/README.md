# Historical migration records

These files are preserved from the local working tree of the retired
`orca-vision-helper` project as migration and audit history. They describe the
source project and the reasoning used while creating `opencode-vision-helper`.

They are not current installation, configuration, security, or product-scope
instructions. Use the repository root README and the active documents in
`docs/` for current behavior. The archived review intentionally records known
limitations of the retired implementation; those findings are historical and
must not be treated as defects in this project without independent verification.
